ENTITY EXTRACTION SERVICE - PROJECT SUMMARY
================================================================================

PROJECT OVERVIEW:
-----------------
A FastAPI-based named entity recognition (NER) service that extracts entities
like PERSON, ORG, and GPE from text using spaCy's en_core_web_sm model.


KEY FEATURES:
-------------

✓ POST /extract_entities endpoint
  - Accepts JSON with text field
  - Returns entities with types
  - Full error handling

✓ Comprehensive Error Handling
  - Empty/invalid inputs → 400
  - Missing fields → 422
  - Server errors → 500

✓ spaCy Integration
  - Uses en_core_web_sm model
  - Extracts 15 entity types
  - Industrial-grade NLP accuracy

✓ Complete Test Suite
  - 10 comprehensive tests
  - All test types: happy path, edge cases, errors
  - 100% endpoint coverage

✓ Production-Ready
  - Uvicorn ASGI server
  - Pydantic validation
  - Proper logging and error handling


QUICK START:
-----------

1. Install dependencies:
   pip install -r requirements.txt

2. Download spaCy model:
   python -m spacy download en_core_web_sm

3. Run the service:
   python app.py

4. Test it:
   curl -X POST "http://localhost:8000/extract_entities" \
     -H "Content-Type: application/json" \
     -d '{"text":"Apple was founded by Steve Jobs."}'

5. Expected response:
   {
     "entities": [
       {"text": "Apple", "label": "ORG"},
       {"text": "Steve Jobs", "label": "PERSON"}
     ]
   }

ENDPOINT SPECIFICATION:
-----------------------

Method: POST
Path: /extract_entities
Content-Type: application/json

Request:
{
  "text": "Your text to analyze"
}

Response (200):
{
  "entities": [
    {"text": "entity text", "label": "LABEL_TYPE"},
    ...
  ]
}

Supported Labels:
  PERSON, ORG, GPE, FAC, LOC, PRODUCT, EVENT, LAW, LANGUAGE,
  DATE, TIME, MONEY, QUANTITY, ORDINAL, CARDINAL

TESTING EXAMPLES:
-----------------

Example 1: Successful Extraction
  POST /extract_entities
  {"text": "Apple was founded by Steve Jobs in California."}
  
  Response:
  {
    "entities": [
      {"text": "Apple", "label": "ORG"},
      {"text": "Steve Jobs", "label": "PERSON"},
      {"text": "California", "label": "GPE"}
    ]
  }

Example 2: No Entities
  POST /extract_entities
  {"text": "The quick brown fox jumps over the lazy dog."}
  
  Response:
  {
    "entities": []
  }

Example 3: Empty Text Error
  POST /extract_entities
  {"text": ""}
  
  Response (400):
  {
    "detail": "Text cannot be empty or contain only whitespace"
  }

Example 4: Missing Field Error
  POST /extract_entities
  {}
  
  Response (422):
  {
    "detail": [{"type": "missing", "loc": ["body", "text"], ...}]
  }

ENTITY TYPES REFERENCE:
-----------------------

PERSON    → People (names, characters)
ORG       → Organizations (companies, agencies)
GPE       → Geopolitical (countries, cities, states)
FAC       → Facilities (buildings, landmarks)
LOC       → Locations (mountains, rivers, non-political)
PRODUCT   → Products (brands, objects)
EVENT     → Events (conferences, wars, sports)
LAW       → Laws (legislation, documents)
LANGUAGE  → Languages (English, French, etc.)
DATE      → Dates (January 1, 2024, etc.)
TIME      → Times (3pm, morning, etc.)
MONEY     → Monetary values ($100, €50, etc.)
QUANTITY  → Measurements (5 kg, 10 meters, etc.)
ORDINAL   → Ordinal numbers (first, second, etc.)
CARDINAL  → Cardinal numbers (5, 100, etc.)
