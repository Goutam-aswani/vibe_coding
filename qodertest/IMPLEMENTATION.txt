ARCHITECTURE:
-------------

Component 1: FastAPI Application (app.py)
  - Framework: FastAPI (modern, fast web framework)
  - Server: Uvicorn (ASGI server)
  - NLP: spaCy (industrial NLP library)

Component 2: Request/Response Models (Pydantic)
  - TextInput: Validates incoming JSON
  - Entity: Represents a single entity
  - EntityResponse: Standardized response format

Component 3: Endpoint: POST /extract_entities
  - Accepts JSON with "text" field
  - Returns JSON with "entities" array
  - Includes full error handling


API SPECIFICATION:
------------------

Endpoint: POST /extract_entities

Request:
--------
Content-Type: application/json

Body:
{
  "text": "string"  # Required, non-empty text
}

Response (200 OK):
------------------
{
  "entities": [
    {
      "text": "string",      # The entity text as found in input
      "label": "string"      # Entity type (PERSON, ORG, GPE, etc.)
    },
    ...
  ]
}

Error Responses:
----------------
400 Bad Request:
{
  "detail": "Text cannot be empty or contain only whitespace"
}

422 Unprocessable Entity (missing/invalid field):
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "text"],
      "msg": "Field required"
    }
  ]
}

500 Internal Server Error:
{
  "detail": "Error processing text: [error message]"
}


INPUT VALIDATION:
-----------------

1. Field Presence:
   - "text" field is required
   - Returns 422 if missing

2. Field Type:
   - Must be string
   - Returns 422 if not string

3. Field Length:
   - Minimum 1 character after stripping
   - Returns 400 if empty after strip()

4. Content Validation:
   - Strips leading/trailing whitespace
   - Rejects whitespace-only text

Example validation flow:
  Input: {"text": "   "}
  After strip: ""
  Result: 400 error


ERROR HANDLING STRATEGY:
-----------------------

Level 1: Request Validation (Pydantic)
  - Missing fields → 422 response
  - Invalid types → 422 response
  - Handled automatically by FastAPI

Level 2: Input Content Validation
  - Empty/whitespace text → 400 response
  - Custom ValueError exception caught

Level 3: Processing Errors
  - spaCy processing issues → 500 response
  - Generic exception handling

Try-except structure:
  try:
    - Strip whitespace
    - Validate non-empty
    - Process with spaCy
    - Extract entities
    return EntityResponse
  except ValueError:
    raise HTTPException(400, detail=...)
  except Exception:
    raise HTTPException(500, detail=...)


SPACY INTEGRATION:
------------------

Model: en_core_web_sm
  - Size: ~40MB
  - Accuracy: Good for most use cases
  - Supports: Tokenization, NER, POS, Dependency parsing
  - License: CC BY-NC-SA 4.0

Loading:
  nlp = spacy.load("en_core_web_sm")

Processing:
  doc = nlp(text)  # Creates Doc object

Entity Extraction:
  for ent in doc.ents:
    text = ent.text      # Entity string (e.g., "Apple Inc.")
    label = ent.label_   # Entity type (e.g., "ORG")

Supported Labels:
  PERSON - People
  ORG - Organizations
  GPE - Geopolitical entities
  FAC - Facilities
  LOC - Locations
  PRODUCT - Products
  EVENT - Events
  LAW - Laws
  LANGUAGE - Languages
  DATE - Dates
  TIME - Times
  MONEY - Money values
  QUANTITY - Quantities
  ORDINAL - Ordinal numbers
  CARDINAL - Cardinal numbers


PYDANTIC MODELS:
----------------

TextInput:
  - Field: text (str)
  - Validation: min_length=1
  - Behavior: Required field, raises 422 if missing

Entity:
  - Field: text (str)
  - Field: label (str)
  - Usage: Individual entity in response

EntityResponse:
  - Field: entities (List[Entity])
  - Usage: Wrapper for response


CODE FLOW:
----------

1. Client sends POST /extract_entities with JSON

2. FastAPI receives request
   ↓
3. Pydantic validates JSON structure
   → If invalid: return 422
   ↓
4. TextInput model validates text field
   → If missing: return 422
   ↓
5. extract_entities() function called
   ↓
6. Strip whitespace from text
   ↓
7. Check if text is non-empty
   → If empty: raise ValueError → 400 error
   ↓
8. Process with spaCy: doc = nlp(text)
   ↓
9. Extract entities: iterate doc.ents
   ↓
10. Build Entity objects with text and label
   ↓
11. Return EntityResponse with entities list
   ↓
12. FastAPI converts to JSON and sends 200 response

COMMON ISSUES AND SOLUTIONS:
----------------------------

Issue: "spacy model not found" error
Solution: python -m spacy download en_core_web_sm

Issue: Port 8000 already in use
Solution: Change port or kill process:
  netstat -ano | findstr :8000
  taskkill /PID [PID] /F

Issue: Import errors in tests
Solution: Ensure app.py is in same directory as test file

Issue: Slow responses with large texts
Solution: Consider adding text length limit

Issue: CORS errors when calling from browser
Solution: Add CORSMiddleware to app (see Security section)
