## Simple Login Automation Bot

A basic browser automation project demonstrating core Selenium patterns for login automation.

### Features

- **Browser Setup**: Chrome WebDriver initialization with optional stealth mode
- **Element Finders**: Multiple strategies to locate elements (ID, XPath, Class)
- **Smart Delays**: Randomized delays to simulate human behavior
- **Error Handling**: Comprehensive exception handling and logging
- **Scrolling**: Smooth scroll-to-view functionality
- **Login Flow**: Complete login sequence with URL change detection

### Project Structure

```
simple_browser_automation/
├── config.py              # Configuration & credentials
├── helpers.py             # Utility functions
├── browser_setup.py       # Browser initialization
├── element_finder.py      # Element location utilities
├── login_bot.py          # Main bot implementation
└── requirements.txt      # Dependencies
```

### Setup & Usage

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure credentials** in `config.py`:
   ```python
   USERNAME = "your_email@example.com"
   PASSWORD = "your_password"
   LOGIN_URL = "https://www.linkedin.com/login"
   ```

3. **Run the bot**:
   ```bash
   python login_bot.py
   ```

### Key Components

- **LoginBot class**: Orchestrates the entire login process
- **Element finders**: Handle various element selection strategies
- **Smart delays**: Prevent bot detection through human-like delays
- **Logging**: Track automation progress and errors

### Configuration Options

- `HEADLESS_MODE`: Run browser in background (invisible)
- `STEALTH_MODE`: Use undetected-chromedriver to bypass bot detection
- `CLICK_DELAY`: Time between actions (seconds)
- `WAIT_TIME`: Max wait time for elements (seconds)

### Browser Automation Concepts Demonstrated

1. **WebDriver Setup** - Initialize Chrome with options
2. **Element Finding** - ID, XPath, Class selectors
3. **Wait Strategies** - Explicit waits with expected conditions
4. **User Simulation** - Randomized delays, scrolling
5. **Error Handling** - Try-catch with logging
6. **Event Detection** - URL change detection for login confirmation
